# Discarded providers and routes

The comparison requires subscription-funded unattended inference and a custom Docker container in which the reviewer can launch Serena MCP. The decision applies to the specified integration. A provider can offer both a retained subscription route and a discarded billing route.

| Analyzed route | Reason for exclusion |
| --- | --- |
| OpenHands native SDK | The evaluated headless adapter required a provider model and a metered API key. The published ACP subscription PR mode targets trusted self-hosted runners. The previous SDK workflow and its secret were removed from the demo. [OpenHands review modes](https://github.com/OpenHands/docs/blob/main/openhands/usage/use-cases/code-review.mdx) |
| Codex Cloud (OpenAI-hosted GitHub review) | The hosted reviewer starts in OpenAI’s `universal` image. Setup scripts can install dependencies. Neither a project-supplied base image nor Docker-in-Docker is a documented way to run the reviewer and Serena in the project image. [Hosted review environment](https://learn.chatgpt.com/docs/environments/cloud-environment#default-universal-image) · [OpenAI Support on nested containers](https://community.openai.com/t/codex-docker-in-docker-in-environment-setup/1272369/22) |
| GitHub-hosted Codex partner agent | The Copilot subscription covers the managed agent. Project-owned agent-image and Serena execution were unverified for that hosted route. [GitHub third-party coding agents](https://docs.github.com/en/copilot/concepts/agent-capabilities/about-agents/about-third-party-coding-agents) |
| Direct Codex CLI with OpenAI Platform credentials | The CLI can run inside Docker and use MCP. Its API-key automation route uses metered inference. Exporting a personal ChatGPT login into this public CI environment was also excluded. The evaluated gh-aw integration uses Copilot inference. [Codex automation authentication](https://developers.openai.com/codex/noninteractive) |
| Codex via gh-aw | Copilot can fund inference and the agent runs in a custom Docker image. Its MCP gateway starts Serena separately. The pinned compiler rejects a native stdio command inside Codex, so this route fails the same-container requirement. The second Dockerfile remains as an independent image experiment. [Custom image and compiler behavior](../reviewers/github-aw/README.md) |
| Cline CLI | Its evaluated unattended PR recipe uses API funding. A supported subscription-backed credential flow for this public CI setup was unverified. [Cline PR review recipe](https://github.com/cline/cline/blob/main/docs/cli/samples/github-pr-review.mdx) |
| goose with Claude ACP | The proposed Claude subscription route still lacks verified unattended credential forwarding and Serena access through ACP. Its API-funded CI route also fails the subscription requirement. [goose ACP providers](https://github.com/aaif-goose/goose/blob/main/documentation/docs/guides/acp-providers.md) |
| Claude with an Anthropic API key, OpenCode with a pay-as-you-go provider, and other direct model APIs | These routes charge a model-provider account for API usage. The demo accepts Claude subscription OAuth and OpenCode Go member credentials for the retained integrations. [Claude Code Action setup](https://github.com/anthropics/claude-code-action/blob/main/docs/setup.md) · [OpenCode Go](https://opencode.ai/docs/console/go/) |
