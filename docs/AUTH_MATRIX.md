## Copilot's unselected GITHUB_TOKEN alternative

GitHub documents inference using `GITHUB_TOKEN` with `copilot-requests: write`. In a personally owned repository it bills the owner's Copilot seat. In an organization repository it bills the organization, subject to its policy/budget; it is not automatically the PAT owner's or triggering user's subscription. This repository selects **only the PAT route** to keep that accounting explicit. Do not add the permission expecting free inference. [Official Actions authentication and billing](https://docs.github.com/en/copilot/concepts/agent-capabilities/agent-powered-workflows-and-operations/copilot-cli-in-github-actions), [workflow setup](https://docs.github.com/en/copilot/how-tos/copilot-cli/use-copilot-cli-in-actions).

## Credential lifecycle

Provision via GitHub's secret UI or interactive `gh secret set NAME`. Token values are never needed in chat. Rotate revoked/expired credentials at the provider and replace the secret; confirm account quotas and organization model access before rerunning. No workflow copies a local account home or falls back to another provider. Actions and registry storage/minutes may have their own costs independently of inference.

For [local reviews](LOCAL_RUNS.md), supply the same named credentials as shell environment variables. GitHub CLI authentication reads the PR but does not authenticate inference or download Actions secrets. The runner forwards only the selected provider credential; it never publishes. Model variables also need local values.

Inference secrets are scoped to the credential check and specific agent step. MCP subprocesses receive an environment allowlist and disposable homes. The browser opens only a trusted local fixture. The publish job has `pull-requests: write` and no inference secret. Standard fork PR checks have no provider secrets. Approval to run fork CI does not grant authorization to transfer account credentials.

Saved ChatGPT account authentication in public/open-source CI is not selected, following [OpenAI's warning](https://learn.chatgpt.com/docs/non-interactive-mode#authenticate-in-automation). This is distinct from supported OpenAI-hosted subscription reviews, GitHub's managed Codex agent, and github-aw Codex with Copilot inference. Those are now included as comparators with their actual environment/tool limitations, rather than excluded for lacking image parity.
